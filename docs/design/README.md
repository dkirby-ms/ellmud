# Design Documents (Archived)

This folder contains design documents from earlier development phases. Many of these designs are **no longer aligned with the current game direction** and should be considered archived reference material only.

## Current Game Direction

As of April 2026, Ellmud has shifted to a **traditional MUD/MMORPG** focus:
- Zone-based exploration (hand-crafted persistent areas)
- Permadeath with persistent consequences
- Real-time combat without extraction mechanics
- Shared-world multiplayer (not instanced arenas)
- De-emphasize PvP in favor of PvE cooperation
