- **Validation:** Optional — dev/test environments work without Azure credentials
- **Type safety:** Compiler enforces null checks on optional `config.azureAI`

### 2. NarrationService Factory (IMPLEMENTED)
- **File:** `packages/server/src/narrative/narration-service-factory.ts`
- **Pattern:** Pure function `createNarrationService()` → instantiates service with conditional LLM transport
- **Graceful Degradation:**
  - When `AZURE_AI_ENDPOINT` + `AZURE_AI_KEY` set → Creates real `AzureAIClient`, wires into NarrationService
  - When not set → NarrationService operates in template-only mode (fast fallback)
- **Testability:** Mock transports can be injected; production code path doesn't require Azure credentials
- **Single source of truth:** Config reading happens once at factory instantiation, not per-call

### 3. ZoneRoom Integration (IMPLEMENTED)
- **File:** `packages/server/src/game/ZoneRoom.ts`
- **Integration point:** `onCreate()` hook calls `createNarrationService()` to instantiate service for the room
- **Entry Narration:** On player entry, calls `generateNarration()` with context (player name, room slug, biome)
- **Output:** Generated prose replaces template text in entry message
- **Fallback:** If LLM unavailable/times out, template text is used (tested and working)
