## Summary

Three GitHub Actions workflows (`release.yml`, `squad-release.yml`, `squad-promote.yml`) were failing due to hardcoded `main` branch reference. Repository uses `dev → uat → prod` branching model.

---

## Root Cause Analysis

**Error:** Workflow run #24201081668: `fatal: ref: main does not exist`

Squad's default template ships with `dev → preview → main` branching. This project's actual strategy is `dev → uat → prod`. Neither `main` nor `preview` branches exist.

---

## Changes Made

### 1. release.yml
- Changed checkout ref: `main` → `prod`
- Updated push target: `main` → `prod`
- Ensures release artifacts push to production branch

### 2. squad-release.yml
- Updated trigger: `on: push to main` → `on: push to prod`
- Aligns squad release pipeline with actual branch strategy

### 3. squad-promote.yml
- Updated promotion path: `dev → preview → main` → `dev → uat → prod`
- Enables full promotion pipeline matching repository strategy
