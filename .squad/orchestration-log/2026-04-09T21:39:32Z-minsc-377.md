## Summary

ZoneRoom's `onJoin()` was missing `STASH_UPDATE` message broadcast to client. Equipment visibility requires both loadout and stash state synchronized.

---

## Root Cause Analysis

**Location:** `packages/server/src/zone/ZoneRoom.ts` (onJoin method)

During RefugeRoom→ZoneRoom merge, `sendZoneLoadoutUpdate()` method was removed without replacement. The new ZoneRoom sent only `LOADOUT_UPDATE` on join, leaving stash empty on client.

---

## Changes Made

### 1. New Combined Method
**File:** `packages/server/src/zone/ZoneRoom.ts`

```typescript
sendLoadoutAndStashUpdate(client: GameClient): void {
  this.sendLoadoutUpdate(client);
  this.sendStashUpdate(client);
}
```

### 2. Equipment Handlers Updated
All handlers that change equipment now call `sendLoadoutAndStashUpdate()`:
- equip/unequip/swap operations
- onJoin handler

### 3. Test Infrastructure
**File:** `packages/server/src/__tests__/MessageCollector.ts`

Updated `MessageCollector` helper to capture both `LOADOUT_UPDATE` and `STASH_UPDATE` messages automatically.
