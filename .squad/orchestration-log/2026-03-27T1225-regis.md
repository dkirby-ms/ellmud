## Key Decisions

- **Rendering:** SVG (React) — CSS-integrated, accessible, event-handling native
- **Minimap:** Replaces `CompassControl.tsx` in sidebar
- **Full Map:** Overlay (z-50) toggled with `M` key
- **Fog of War:** True fog — unexplored rooms hidden, adjacent rooms dim ghosts
- **State Management:** Local `useExplorationMap` hook (not global AppState)
- **Message Types:** Two new types — `exploration_data` (bulk join) and `exploration_update` (incremental)
- **Procedural Shards:** BFS layout computed client-side; maps ephemeral
- **Zone Maps:** Cached in-session; zone maps persist across transfers
