## Bugs Fixed

### Bug 1: zoneSlug not derived from room name
- **Symptom:** Players joining `zone:the-refuge` landed in procedural shards instead
- **Root cause:** Client calls `joinOrCreate("zone:the-refuge", { token })` without passing `zoneSlug` in options
- **Fix:** `ShardRoom.onCreate()` now parses `zoneSlug` from `roomName` when it starts with `zone:`
- **Files:** `packages/server/src/rooms/ShardRoom.ts`

### Bug 2: ROOM_SWITCH target mismatch
- **Symptom:** Extraction and death room switches failed due to wrong target name
- **Root cause:** Sent `target: 'refuge'` but Colyseus room defined as `'zone:the-refuge'`
- **Fix:** Updated both ROOM_SWITCH sends to use full room name `'zone:the-refuge'`
- **Files:** `packages/server/src/rooms/ShardRoom.ts`
