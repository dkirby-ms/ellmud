### Findings

PR #292 wires NarrationService + LLM client into ZoneRoom lifecycle hooks. Architecture and factory pattern approved. However, `onJoin()` awaits `generateNarration()` call, blocking player join flow.

### Blocking Issue

- **Line 486:** `await this.generateNarration('event', playerId, startRoom, 'You step through the rift...')`
- **Impact:** Blocks player state delivery for 0-2000ms (LLM latency + cache miss)
- **Violation:** GDD §4.5 — "LLM never blocks critical path"
- **UX:** Player sees "connecting..." spinner during join phase

### Required Fix

Change to fire-and-forget pattern:

```typescript
this.generateNarration('event', playerId, startRoom, 'You step through the rift...')
  .then((text) => {
    this.sendNarrate(client, {
      text,
      type: 'system',
      timestamp: Date.now(),
    });
  })
  .catch((err) => {
    this.log(`Entry narration error: ${err}`);
  });
```

### Approved Elements

- ✅ Factory pattern for NarrationService injection
- ✅ Fallback logic and timeout handling (2000ms)
- ✅ Test coverage structure
- ✅ Type safety in service wiring
