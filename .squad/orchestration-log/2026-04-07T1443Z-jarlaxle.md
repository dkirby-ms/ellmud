## Summary

Designed combat sandbox mechanics using per-player CombatSystem instances for isolation and flexibility. Key design decisions:

- Separate CombatSystem instance per player instead of flags on zone combat system
- Sandbox creatures tagged with `sandbox: true` flag
- Player state snapshotted on sandbox entry, restored on reset/exit
- Sandbox tick timer independent of zone tick (enables speed/pause/step)
- All sandbox commands gated behind `devModeEnabled`
- Full combat isolation prevents pollution of production combat loop

## Mechanics

- Sandbox creatures excluded from loot, XP, repop, and corpse systems
- Independent tick timer enables experimentation with combat pacing
- Real damage formula ensures sandbox results reflect actual combat behavior
