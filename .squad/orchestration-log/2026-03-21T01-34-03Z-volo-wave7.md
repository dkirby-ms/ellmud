## Technical Delivery

### Component: ChatSocialPanel

**Responsibility:**
- Display proximity-based chat messages (players within communication range)
- Filter messages by distance (configurable range, default TBD from GDD)
- Show sender nicknames and message timestamps
- Allow players to send chat messages
- Integrate with room-level chat state (Colyseus Room broadcast)

**Props:**
- `messages: ChatMessage[]` — filtered proximity messages
- `playerNickname: string` — current player's display name
- `onSend(text: string)` — handler for sending messages
- `proximityRange: number` — distance in game units for chat filtering

**Message Format:**
```typescript
interface ChatMessage {
  id: string
  sender: string
  text: string
  timestamp: number
  distance: number // distance from current player
}
```
