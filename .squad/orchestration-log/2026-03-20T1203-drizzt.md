## Problem Statement

POST `/matchmake/joinOrCreate/refuge` returned 404 after UAT deployment. The Colyseus matchmaking HTTP routes were never being registered because `Server.listen()` was not called before the server started accepting requests.

**Root Cause:** `packages/server/src/index.ts` was calling `app.listen(PORT)` directly, passing the already-listening HTTP server to the Colyseus transport. This bypassed Colyseus's internal `bindRouterToTransport()` call, leaving matchmaking routes unregistered.

---

## Solution

Restructured server initialization to call `http.createServer(app)` first, instantiate Colyseus `Server` with the HTTP server, then call `server.listen(PORT)`. This ensures `bindRouterToTransport()` registers all matchmaking routes before the server accepts connections.

**File Modified:**
- `packages/server/src/index.ts`

**Pattern (preserved for all agents):**
```typescript
const httpServer = http.createServer(app);
const server = new Server({
  transport: new WebSocketTransport({ server: httpServer }),
});
server.define('refuge', RefugeRoom);
await server.listen(PORT);
```
