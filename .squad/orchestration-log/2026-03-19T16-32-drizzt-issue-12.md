### Key Decisions

1. **Optional auth by default:** Development workflow unaffected. Set `AUTH_REQUIRED=true` for enforcement.
   - Clients joining without tokens get `playerId: 'anonymous'`
   - Production uses env var to require login
   - Compatibility: Existing tests pass unchanged

2. **In-memory token store for Phase 1:** Fast expiry management without external deps.
   - Tokens cleaned up after TTL (24 hours)
   - Ready to swap to Redis later (interface-based design)

3. **Bcrypt with 12 salt rounds:** Industry-standard password security.
   - Hashing is computed in worker thread (non-blocking)
   - Original plaintext passwords never logged

4. **JWT structure:** `{ playerId, username, issuedAt, expiresAt }`
   - Refresh endpoint extends the TTL without requiring password re-entry
   - Stateless validation (no server lookup required on join)
