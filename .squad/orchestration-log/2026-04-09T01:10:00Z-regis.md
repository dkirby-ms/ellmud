### settings-api.ts Client

### useSettings Hook
- Initializes from localStorage cache, async fetches from server on token change
- Methods: `updateSetting(key, value)`, `resetToDefaults()`
- Loading state tracking (Syncing… indicator)
- Optimistic writes (update state immediately, sync in background)
- Fire-and-forget PUT (no error throw, just log)
- Merge strategy: server config overwrites cache on fetch, client edits layer on top

## Design Decisions Applied
- **Self-contained settings API** (avoid global 401 cascade)
- **localStorage as cache** (offline UX, draft edits)
- **Optimistic writes** (immediate feedback, lazy sync)
- **Graceful degradation** (settings work even if server unreachable)
- **Scope boundaries:** No macro system, no .rcfile parsing in v1
