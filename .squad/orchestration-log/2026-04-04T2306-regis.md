## Incident Summary

User reported zone designer corruption:
- No exits/edges visible between rooms
- Rooms displayed in wrong positions
- React Flow console errors

---

## Root Causes Identified & Fixed

### Bug 1: Edges Not Rendering
**Root:** Missing `Handle` components in `ZoneRoomNode.tsx`. React Flow requires explicit Handle elements on nodes for edges to connect.

**Fix:** Added Handle components (top, bottom, left, right positions) with `isConnectable={false}` to prevent user-driven connections.

**Files:** `ZoneRoomNode.tsx`

---

### Bug 2: Room Position Double-Scaling
**Root:** `elkLayout.ts` applied position scaling (×100), then `ZoneDesigner.tsx` applied it again (×100), resulting in rooms at (10000×, 10000×) instead of expected positions.

**Fix:** 
- Removed position scaling from `elkLayout.ts` — ELK returns positions in layout units, no transformation needed
- Removed position multiplication (`* 100`) from `ZoneDesigner.tsx` — positions already correct from ELK
- Updated edge source/target handles to match node Handle names: `sourceHandle="right"`, `targetHandle="left"`
- Updated position assertions in `elk-layout.test.ts` to match new behavior
- Added `@xyflow/react` mock in `zone-room-node.test.tsx` to prevent Handle import errors

**Files:** 
- `elkLayout.ts`
- `ZoneDesigner.tsx`
- `elk-layout.test.ts`
- `zone-room-node.test.tsx`
