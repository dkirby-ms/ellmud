### Key Decisions

1. **In-memory cache default, Redis switchable:** Interface-based design allows swap at config time.
   - Phase 1: LRU cache (fast, no external deps)
   - Phase 3: Pass `RedisNarrationCache` instance to NarrationService
   - No code changes needed for migration

2. **LLMTransport function type, not SDK class:** Flexible transport layer.
   - `createAzureTransport(config)` returns async function matching `(prompt, context) => string`
   - Tests inject mock functions — no Azure SDK in test suite
   - Ready for anthropic.js, local ollama, or other backends

3. **Fallback template library:** Guaranteed narration even if LLM is unavailable.
   - Every action type (strike, dodge, flee, take, drop, etc.) has built-in template
   - LLM enrichment is optional — game remains playable without it
   - SHA-256 content hash prevents re-querying identical prompts

4. **Telemetry hooks at delivery:** Structured logging for cost tracking and performance analysis.
   - Cache hit rate visible in metrics
   - LLM cost per narration line tracked (token counting)
   - Audit trail of which enrichments were LLM vs fallback
