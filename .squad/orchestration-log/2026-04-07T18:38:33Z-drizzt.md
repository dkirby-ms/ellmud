## Implementation Details

### Two Modes

1. **`help` (no args)** — Lists all available commands grouped by 7 categories
   - Dynamic filtering: hides feature room commands not available in current location
   - Dev command filtering: respects `getConfig().devModeEnabled` flag

2. **`help <command>` (with args)** — Detailed help for specific command
   - Shows description, usage, and aliases
   - Works with both primary names and aliases (e.g., `help ?` resolves to help command)

### Design Patterns

- **Static metadata registry:** `COMMAND_HELP` object contains metadata for all commands
- **Context filtering:** Room type and dev mode gating follows established patterns from `handleGoto` and `featureHandlers`
- **Category organization:** 7 logical groups (Navigation, Items, Communication, Combat, Special Actions, Feature Rooms, Dev Tools)
- **System narration:** Help output uses `type: 'system'` for clean separation from game narrative
