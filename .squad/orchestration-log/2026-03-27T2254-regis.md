## Work Summary

Implemented a classic MUD-style status line (the `MudPrompt` component) pinned to the bottom of the game narrative scroll, displaying player status and a blinking cursor prompt.

### Implementation

- **Component:** `packages/client/src/components/MudPrompt.tsx`
  - Renders HP (color-coded based on health %)
  - Shows combat stance (Ready / Engaged / etc.)
  - Lists active status effects (buffs/debuffs with icons)
  - Displays current room name
  - Animated blinking `>` cursor at end of line
  
- **Styling:** `.mud-prompt-*` classes in `packages/client/src/styles/tailwind.css`
  - Uses `position: sticky; bottom: 0; z-index: 2` inside `.narrative-scroll` container
  - Integrates with responsive layout and dark mode palette
  
- **Integration:** Reads all data from AppContext (no new server message types required)
  - Hooks into existing `useAppContext()` for HP, stance, effects, current room
  - Ready for MP/mana field when server schema includes it (zero changes needed)

### Design Decisions

- **Sticky positioning inside scroll container:** The MudPrompt is a child of `.narrative-scroll`, so `sticky; bottom: 0` pins it within that div's overflow area (classic MUD UX pattern)
- **No new message types:** Reuses existing sync packets — zero protocol churn
- **Future-proof for mana:** Field is pre-stubbed in the component; just add to AppContext when schema changes
