## Summary

Designed combat sandbox as a feature room type inside persistent zones like The Refuge. Established server-side command infrastructure and safety gates:

- Feature room type (`feature_sandbox`) following stash/board/inn pattern
- No new Colyseus room type needed; reuses existing infrastructure
- Selective combat ticking: sandbox rooms opt in to combat even in non-combat zones
- On-demand creature spawning via new `CreatureManager.spawnCreatureInRoom()` method
- Double access gate: feature room gate + `devModeEnabled`
- No death penalty in sandbox via `sandboxRoomIds.has(roomId)` bypass

## Technical Architecture

- **Room type pattern:** Follows feature room conventions (stash, board, inn)
- **Creature spawning:** New CreatureManager method for runtime spawning; existing seeding path unaffected
- **Safety:** Double-gated access prevents accidental production exposure
- **Combat ticking:** Selective ticking with guard in `ZoneRoom.update()` to check for sandbox room activity
