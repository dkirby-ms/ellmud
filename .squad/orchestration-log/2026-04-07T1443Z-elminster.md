## Summary

Architected the combat sandbox as three feature rooms inside the Refuge zone, following established feature-room patterns. Established key architecture decisions:

- Three new RoomTypes: `feature_sandbox`, `feature_sandbox_arena`, `feature_sandbox_stats`
- State isolation via `sandboxMode` flag on CommandContext
- Uses real CombatSystem instance with sandbox-controlled lifecycle and side-effects
- All sandbox commands dev-gated behind `getConfig().devModeEnabled`
- New SandboxService in `packages/server/src/sandbox/` for creature spawning and stat overrides
- Phased delivery: Phase 1 (spawn/fight/reset/log), Phase 2 (stat tuning), Phase 3 (scenario save/load/replay)
