## Learnings

Adapter pattern chosen over type unification because:
- Shared `Room.items` is `LootContainer[]` (containers with item ID arrays)
- Command handlers expect `Item[]` (objects with name, weight, description)
- Unifying would require rewriting every handler that touches items
- Adapter converts only at ShardRoom boundary; zero changes to existing command system
