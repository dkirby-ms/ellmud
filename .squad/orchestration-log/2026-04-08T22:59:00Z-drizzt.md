## Root Cause Analysis
The admin "Room Graph" tab displays spawned creatures alongside rooms. For procedural zones (e.g., ZoneDesigner), the zone-data fetch always returned null because procedural zones have no `zoneSlug`. The `roomOccupancy` useMemo fell back to an empty map, silently hiding all creature display. Meanwhile, the server was sending fresh `roomGraphRooms[]` in the zone-detail response, but the client wasn't using it.

## Fix (Two Parts)

### Part 1: Server Response Enhancement
- Updated `getZoneDetail()` endpoint to include `roomGraphRooms[]` serialization from live zone state
- No backward-breaking change: added as optional field
- Ensures authoritative room graph always available to client

### Part 2: Client Occupancy Logic
- Updated `roomOccupancy` useMemo to use fallback chain: zone-data rooms → room-graph rooms → empty
- Added new `displayRooms` memo that normalizes both sources
- Room Graph tab now displays creatures correctly for both static zones (zone-data) and procedural zones (room-graph)
