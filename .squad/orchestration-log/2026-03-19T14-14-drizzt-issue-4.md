## Technical Decisions Applied

### Schema Definition: `defineTypes()` vs Decorators
**Decision:** Use `defineTypes(MyClass, { field: 'type' })` instead of `@type()` decorators

**Rationale:**
- TypeScript 5.9.3 (required by @colyseus/schema v4.0.x) uses native TC39 Stage 3 decorators
- Legacy `PropertyDecorator` signature incompatibility with runtime transpilers (tsx, esbuild)
- `defineTypes()` is explicit, stable, and transpiler-agnostic

**Enforcement:** Integration test validates message-only protocol compliance
