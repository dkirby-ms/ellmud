## Problem Statement

The Zone Designer admin tool had foundational support for NPC and loot management in the data model, but lacked UI components for managing them:

1. **No NPC Management UI** — Admins couldn't add/edit NPCs spawned in rooms via the UI
2. **No Loot Management UI** — No way to configure loot containers and items from admin interface
3. **Cramped Details Panel** — Side panel (256px width) too narrow for comfortable form editing
4. **No Creature Template Discovery** — Admin API didn't expose available creature templates

## Solution Overview

### 1. Resizable Room Details Panel

**Implementation:**
- Converted fixed-width panel (w-64: 256px) to resizable container (280px–600px)
- Added 4px drag handle on left edge with hover effect (subtle background color)
- Default width: 320px (w-80)
- Uses React state to track panel width during drag

**Technical Details:**
```
- onMouseDown on drag handle → track mouse position
- onMouseMove → calculate delta, update width state
- onMouseUp → finalize width
- Constraints: min 280px, max 600px
```

### 2. NPC Management Section

**UI Component:**
- Label: "NPCs"
- Table-like view with rows for each spawned creature
- Columns: Creature ID (dropdown), Spawn Count (number input), Remove button
- "Add NPC" button to create new row with defaults

**Data Binding:**
```typescript
RoomNPC {
  creatureId: string;    // e.g., "drowned_revenant"
  spawnCount: number;    // e.g., 2
}
```

**API Integration:**
- Fetches creature templates from `GET /admin/api/creature-templates`
- Populates dropdown with all available templates
- Sends updates with existing room CRUD endpoints

### 3. Loot Management Section

**UI Component:**
- Label: "Loot Containers"
- Similar table layout with rows for each loot item
- Columns: Item ID (dropdown), Quantity (number input), Remove button
- "Add Loot" button to create new row

**Data Binding:**
```typescript
RoomLootContainer {
  itemId: string;        // e.g., "bent_rebar"
  quantity: number;      // e.g., 5
}
```

**API Integration:**
- Fetches items from `GET /admin/api/items`
- Populates dropdown with all registered items
- Integrates with existing zone room update API

### 4. New Admin API Endpoints

**Endpoint 1: `GET /admin/api/creature-templates`**
```
Response: {
  templates: CreatureTemplate[],
  count: number
}
```
- Returns all creature templates from `CREATURE_TEMPLATES` registry
- Used to populate NPC dropdown in Zone Designer

**Endpoint 2: `GET /admin/api/items`**
```
Response: {
  items: ItemDefinition[],
  count: number
}
```
- Returns all item definitions from `ITEM_REGISTRY`
- Used to populate loot item dropdown in Zone Designer
