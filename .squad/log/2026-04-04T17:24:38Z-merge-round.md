## Migration Discipline Decision

**New Rule:** Seed file edits must pair with numbered migrations for existing databases.

**Context:** PR #260 modified `003_seed_zones.sql` (Refuge category update) but didn't add corresponding UPDATE migration. The migration runner tracks by filename — once applied, seed files are never re-executed.

**Fix Pattern:** `014_repurpose_refuge.sql` added by Drizzt with UPDATE statement:
```sql
UPDATE zones SET category = 'dev', description = '...' WHERE slug = 'the-refuge';
```

**Team Learning:** This is now a documented decision in `.squad/decisions/inbox/` for future reference.
